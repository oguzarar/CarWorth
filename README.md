
Bu proje, Kotlin Jetpack Compose ile geliştirilmiş bir mobil uygulama ve Python’da CatBoost ile eğitilmiş arac fiyat tahmini modelini içerir.

<p>Frontend: Kotlin, Jetpack Compose</p>
<p>Veri Toplama: BeautifulSoup (Web scraping)</p>
<p>Veri İşleme: Pandas (Veri temizleme ve manipülasyon)</p>
<p>Makine Öğrenimi: CatBoost (Model eğitimi ve tahmin)</p>
<p>Backend API: FastAPI (Python web framework)</p>
<p>İletişim: HTTP istekleri (Kotlin'den Python API'sine)</p>
